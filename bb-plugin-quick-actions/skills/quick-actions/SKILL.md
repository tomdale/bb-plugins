---
name: quick-actions
description: Configure the Quick Actions BB plugin or explain which actions its ring shows. Use when changing the menu trigger, right-click, corner, or motion, when choosing or reordering the ring's actions, or when diagnosing an action missing or unavailable in it.
---

Read settings with `bb plugin config quick-actions --json`.

Set `trigger` to `hold-option` (hold Option over a thread pane; the default) or `corner` (a button at the composer's corner) with `bb plugin config quick-actions set trigger <value>`. `rightClick` (default `true`, with either trigger) opens the ring when a thread pane is right-clicked, except on fields, links, media, selected text, and targets with their own menu, which keep the browser's menu; set it to `false` to keep the browser's menu everywhere. Set `corner` to `bottom-left`, `bottom-right`, `top-left`, or `top-right`, and `motion` to `ring` (Ring bloom) or `arc` (Arc spring); both apply to the corner trigger only. Set `debugRegions` to `true` to draw the corner trigger's circular core and radial hit corridors, or `false` to hide them. `bb plugin config quick-actions unset <key>` restores a default.

The ring shows the BB thread actions the user picked under Settings → Plugins → Quick Actions → Actions, in ring order clockwise from the top, at most ten. The default is Archive, Pin, Mark read / unread, and Copy link. The Quick Actions server stores the list (`ringActions` and `setRingActions` RPCs; `setRingActions` with `actions: null` restores the default), each entry a thread action `key` (`<plugin id>/<registration id>`) with the title and icon it had when picked, and every open window reloads it when it changes. Change the list in that settings section or through `setRingActions`. The picker lists `experimental_useThreadActionRegistrations()`, so any plugin's registered thread action can be added, such as `workstreams/snooze`. Each action shows the label, icon, and disabled state BB's thread menus show for the thread. An action the thread lacks, or whose plugin is gone, keeps its slot as unavailable, so the other directions stay put. Each action with choices grows its own band in the hold ring; the choice whose label equals the action's `detail` is lit, and releasing on the action itself, or running it from the corner menu, takes that choice, or passes no value when no choice matches.

When an action is missing from the ring, check that it is in the Actions list. When it shows as unavailable, check that its plugin is running (`bb plugin list`) and that BB's thread menu shows the action for that thread. The plugin's `README.md` lists the verification commands.
