Quick Actions puts thread actions in a radial menu at the pointer. Holding
Option over a thread pane opens a labelled ring centred on the cursor over a
slight window dim,
and releasing Option runs the action the pointer points toward, so archiving or
snoozing happens where the hand already is. Releasing in the hub cancels. A
corner trigger remains available as an alternative.

The menu runs BB's native Archive, Pin, Mark read or unread, and Copy link
actions. Snooze stores wake generations on the BB server, archives the current
thread and its active descendants after confirmation, and unarchives the same
set at the chosen wake time. In the hold ring, a band past Snooze's label
offers presets from In 1 hour to Next week; otherwise Snooze wakes at 9:00 AM
the next day in the server's time zone. Manual unarchive
cancels that thread's wake record.

Settings select the trigger, plus the corner trigger's corner and motion, with
an optional debug view of its circular core and radial hit corridors. Changes
apply to open windows without reloading the plugin.
